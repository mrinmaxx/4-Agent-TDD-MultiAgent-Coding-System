problem          : Implement in a file called solution.py:

    def min_cost_drive(
        n: int,
        roads: list[list[int]],
        fuel_stations: dict,      # {city_index: refuel_cost}
        capacity: int,
        start: int,
        target: int,
    ) -> int

You drive a car on a directed graph of n cities (0..n-1). Each road is [u, v, dist]:
a one-way road from u to v costing `dist` units of fuel to traverse. Your tank holds
at most `capacity` fuel and you START at `start` with a FULL tank.

REFUELING IS THE CORE MECHANIC: certain cities are fuel stations (given in
fuel_stations as {city: cost}). At a fuel station you MAY refuel your tank back up to
FULL capacity, paying that station's cost each time you do so. You can refuel at the
same station multiple times if you pass through it again. Refueling is OPTIONAL.

You may pass through any city multiple times. You may only traverse a road if your
current fuel is >= that road's dist (fuel can never go negative).

GOAL: return the MINIMUM TOTAL REFUELING COST to get from start to target.
- If you can reach target without ever refueling, cost is 0.
- If target cannot be reached even WITH optimal refueling, return -1.
- start == target returns 0 immediately.
- A single road with dist > capacity can never be traversed.

You are minimizing total REFUEL COST, NOT distance and NOT number of roads. The
cheapest-cost route may be longer than the shortest route.

HINT: the state is (city, fuel_remaining), and this is a shortest-path problem over
that state space (Dijkstra), where "distance" being minimized is refuel cost. Refueling
at a station is a state transition: from (city, f) you may move to (city, capacity) by
paying that station's cost. Model it this way — a solution that ignores refueling as a
state transition will wrongly return -1 whenever a trip needs more than one tank.

Include a docstring explaining the state-space formulation and complexity. No test code.
